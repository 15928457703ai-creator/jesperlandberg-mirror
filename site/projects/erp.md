# 华润ERP

华润ERP 1.0 制造业数字化：从 0 到 1 搭建移动端 ERP 体验，覆盖生产、采购、库存与仓库管理四大核心流程，为 60+ 工厂的仓管与操作员提供日常指令、入库与退货服务，解决办公场景转移下电脑无法移动的作业瓶颈。
