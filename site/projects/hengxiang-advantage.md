# 横向优势

横向优势：以视觉表现为核心的能力横向拓展，覆盖插画、3D 渲染与 AIGC 运用。作为视觉中国签约插画师，将插画与 3D 输出沉淀为可复用的材质库与 IP 资产，落地到运营项目（渠道订货、在线对账、政策可视），并运用 AIGC 制作比赛宣传、年末贺岁、数字人采访等视频，为各业务线设计落地 IP。
